UZBEKISTAN 3D RACING
====================

ISHGA TUSHIRISH:
1. ZIP faylni kompyuterga yuklab oling va Extract All qiling.
2. Papkani Visual Studio Code'da oching.
3. index.html faylini Chrome yoki Edge brauzerida oching.
4. Internet yoqilgan bo‘lishi kerak: Three.js va Google Fonts CDN orqali yuklanadi.

O‘YIN:
- Xarita: Toshkent, Samarqand, Buxoro, Farg‘ona, Namangan, Xiva.
- Mashina: Neon GT, Turbo X, Gold Viper.
- Chap/o‘ng: klaviaturada ← → yoki A/D.
- Nitro: SPACE.
- Telefon: ekrandagi chap, o‘ng va ⚡ tugmalari.
- ESC: pauza.

Eslatma:
Bu mustaqil arcade poyga prototipi. Mashinalar, yo‘l va shahar muhitlari
Three.js yordamida real vaqt rejimida 3D shakllarda chiziladi.
